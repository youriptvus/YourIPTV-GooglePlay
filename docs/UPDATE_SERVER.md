# Play update delivery

Google Play delivers updates for this independent distribution. No executable customer manifest/download/installer route. Customer GitHub/website updater remains unchanged in separate project; no server deployment authorized.

No REQUEST_INSTALL_PACKAGES, UPDATE_PACKAGES_WITHOUT_USER_ACTION or updater SYSTEM_ALERT_WINDOW purpose. Final merged-manifest/executable audit in current test report is authority. Mobile/tablet/ChromeOS support optional Play in-app update APIs; TV does not. Normal Play delivery needs no new API dependency. User-source playback does not require Play connectivity.

Never configure new project to upload to customer releases/update endpoints or restore APK installer. See Play signing/Console owner gates.
