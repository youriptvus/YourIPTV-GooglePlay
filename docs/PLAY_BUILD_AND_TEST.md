# Maintained build and development procedure

The permanent development source is YourIPTV-GooglePlay/main. Version 1.1.1/code52 is the published baseline; infrastructure and unpublished corrections do not authorize rebuilding/replacing it. Customer source is exported by the controlled one-way Actions workflow after an owner push and initial bootstrap review.

Follow [Development workflow](DEVELOPMENT_WORKFLOW.md) for both source-selection checks, authentication, candidate review and future explicitly authorized signed local release pairs. See [Security and signing](SECURITY_AND_SIGNING.md) for independent keys/certificates, API compatibility and private-file protection. Closed testing, testers, opt-in links and Console releases are unchanged by source migration.

Historical operational handoffs and device records are private local evidence and remain preserved outside the maintained public procedure.
